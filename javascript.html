⚡ JavaScript শিখুন

JavaScript কী?

JavaScript হলো এমন একটি ভাষা যা দিয়ে ওয়েবসাইটকে জীবন্ত বা ইন্টারঅ্যাক্টিভ করা যায়। আপনি যখন কোনো ওয়েবসাইটে কোনো বাটনে ক্লিক করেন এবং সাথে সাথে কিছু পরিবর্তন হয়, তার পেছনে JavaScript কাজ করে।

১. প্রথম প্রোগ্রাম: Hello World

স্ক্রিনে মেসেজ দেখানোর সবচেয়ে সহজ উপায় হলো console.log ব্যবহার করা:

console.log("Hello, Zakirhub!");

২. ভেরিয়েবল (Variable)

JavaScript-এ ভেরিয়েবল তৈরি করতে let বা const ব্যবহার করা হয়।

let name = "Zakir";
const age = 25;
console.log("আমার নাম " + name);

৩. অ্যালার্ট (Alert) ও ইনপুট

ব্রাউজারে একটি পপ-আপ মেসেজ দেখাতে alert এবং ইউজারের কাছ থেকে তথ্য নিতে prompt ব্যবহার করা হয়:

let userName = prompt("আপনার নাম কী?");
alert("হ্যালো, " + userName);

৪. শর্ত (If-Else)

কোনো শর্ত সত্য বা মিথ্যা তার উপর ভিত্তি করে সিদ্ধান্ত নিতে if-else কাজ করে।

let age = 18;
if (age >= 18) {
    console.log("আপনি ভোট দিতে পারবেন");
} else {
    console.log("আপনি ভোট দিতে পারবেন না");
}

৫. লুপ (Loop)

একই কাজ বারবার করার জন্য for লুপ ব্যবহার করা হয়:

for (let i = 1; i <= 5; i++) {
    console.log("সংখ্যা: " + i);
}

(আরও নতুন পাঠ শীঘ্রই যোগ করা হবে...)
