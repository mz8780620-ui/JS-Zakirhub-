⚡ JavaScript শিখুন

JavaScript কী?

JavaScript হলো এমন একটি ভাষা যা দিয়ে ওয়েবসাইটকে জীবন্ত বা ইন্টারঅ্যাক্টিভ করা যায়। আপনি যখন কোনো ওয়েবসাইটে কোনো বাটনে ক্লিক করেন এবং সাথে সাথে কিছু পরিবর্তন হয়, তার পেছনে JavaScript কাজ করে। এটি ওয়েব ডেভেলপমেন্টের জন্য সবচেয়ে গুরুত্বপূর্ণ ভাষা।

১. প্রথম প্রোগ্রাম: Hello World

স্ক্রিনে মেসেজ দেখানোর সবচেয়ে সহজ উপায় হলো console.log ব্যবহার করা:

console.log("Hello, Zakirhub!");

২. ভেরিয়েবল (Variable)

JavaScript-এ ভেরিয়েবল তৈরি করতে let বা const ব্যবহার করা হয়।

let name = "Zakir";
const age = 25;
console.log("আমার নাম " + name);

৩. অ্যালার্ট (Alert)

ব্রাউজারে একটি পপ-আপ মেসেজ দেখাতে alert ব্যবহার করা হয়:

alert("JS Zakirhub-এ স্বাগতম!");
