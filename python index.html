🐍 Python শিখুন

Python কী?

Python হলো একটি সহজ এবং শক্তিশালী প্রোগ্রামিং ভাষা। এটি শেখা সহজ, কারণ এর কোডগুলো প্রায় ইংরেজির মতো পড়া যায়। ওয়েব ডেভেলপমেন্ট, ডেটা সায়েন্স, কৃত্রিম বুদ্ধিমত্তা (AI) এবং অটোমেশনে Python ব্যাপকভাবে ব্যবহৃত হয়।

১. প্রথম প্রোগ্রাম: Hello World

প্রোগ্রামিং শেখার প্রথম ধাপ হলো স্ক্রিনে কিছু লেখা। Python-এ এটি খুবই সহজ:

print("Hello, Zakirhub!")

২. ভেরিয়েবল (Variable)

ভেরিয়েবল হলো একটি বাক্সের মতো, যেখানে আমরা ডেটা বা তথ্য জমা রাখি।

name = "Zakir"
age = 25
print("আমার নাম", name)
print("আমার বয়স", age)

৩. গণিত (Math)

Python দিয়ে সহজেই যোগ, বিয়োগ, গুণ, ভাগ করা যায়।

a = 10
b = 5
print("যোগফল:", a + b)
print("গুণফল:", a * b)
