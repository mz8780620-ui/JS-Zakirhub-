Java কী?

Java হলো একটি শক্তিশালী অবজেক্ট-ওরিয়েন্টেড প্রোগ্রামিং ভাষা। এটি মূলত বড় অ্যাপ্লিকেশন, অ্যান্ড্রয়েড মোবাইল অ্যাপস এবং এন্টারপ্রাইজ সিস্টেম তৈরি করতে ব্যবহৃত হয়। Java-এর সবচেয়ে বড় সুবিধা হলো এটি একবার লিখলে যেকোনো ডিভাইসে (যেখানে Java আছে) চালানো যায়।

১. প্রথম প্রোগ্রাম: Hello World

Java-তে স্ক্রিনে কিছু প্রিন্ট করতে হলে একটি ক্লাস এবং main মেথড লিখতে হয়:

public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, Zakirhub!");
    }
}

২. ভেরিয়েবল (Variable)

Java-তে ভেরিয়েবল ডিক্লেয়ার করার সময় এর ডেটা টাইপ (যেমন int, String) উল্লেখ করতে হয়।

String name = "Zakir";
int age = 25;
System.out.println("আমার নাম " + name);
System.out.println("আমার বয়স " + age);

৩. কন্ডিশন (If-Else)

শর্ত অনুযায়ী সিদ্ধান্ত নিতে if-else ব্যবহার করা হয়:

int number = 10;
if (number > 0) {
    System.out.println("সংখ্যাটি ধনাত্মক");
} else {
    System.out.println("সংখ্যাটি ঋণাত্মক");
}
