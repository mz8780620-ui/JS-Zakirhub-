☕ Java শিখুন

Java কী?

Java হলো একটি শক্তিশালী অবজেক্ট-ওরিয়েন্টেড প্রোগ্রামিং ভাষা। এটি মূলত বড় অ্যাপ্লিকেশন, অ্যান্ড্রয়েড মোবাইল অ্যাপস এবং এন্টারপ্রাইজ সিস্টেম তৈরি করতে ব্যবহৃত হয়।

১. প্রথম প্রোগ্রাম: Hello World

Java-তে স্ক্রিনে কিছু প্রিন্ট করতে হলে একটি ক্লাস এবং main মেথড লিখতে হয়:

public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, Zakirhub!");
    }
}

২. ভেরিয়েবল (Variable)

Java-তে ভেরিয়েবল ডিক্লেয়ার করার সময় এর ডেটা টাইপ উল্লেখ করতে হয়।

String name = "Zakir";
int age = 25;
System.out.println("আমার নাম " + name);

৩. ইউজারের কাছ থেকে ইনপুট নেওয়া (Input)

Java-তে ইনপুট নিতে Scanner ক্লাস ব্যবহার করা হয়। (এর জন্য উপরে import java.util.Scanner; লিখতে হয়)

import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("আপনার নাম কী? ");
        String name = sc.nextLine();
        System.out.println("হ্যালো, " + name);
    }
}

৪. শর্ত (If-Else)

শর্ত অনুযায়ী সিদ্ধান্ত নিতে if-else ব্যবহার করা হয়:

int age = 18;
if (age >= 18) {
    System.out.println("আপনি ভোট দিতে পারবেন");
} else {
    System.out.println("আপনি ভোট দিতে পারবেন না");
}

৫. লুপ (Loop)

একই কাজ বারবার করার জন্য for লুপ ব্যবহার করা হয়:

for (int i = 1; i <= 5; i++) {
    System.out.println("সংখ্যা: " + i);
}

(আরও নতুন পাঠ শীঘ্রই যোগ করা হবে...)
